# tp_exam

## Adresses physiques du code utilisateur

```
USER1 memory range :            [0x1000000 - 0x1ffffff]
USER2 memory range :            [0x2000000 - 0x2ffffff]
```

## Adresses virtuelles utilisateur

**User1 :**

```
pgd  :            0x1100000
ptb0 :            0x1101000
ptb1 :            0x1102000
ptb2 :            0x1103000
```

**User2 :**

```
pgd  :            0x2100000
ptb0 :            0x2101000
ptb1 :            0x2102000
ptb2 :            0x2103000
```
